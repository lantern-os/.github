# LanternOS

**An AI-native, privacy-first operating system built around capabilities, security,
decentralisation, and open hardware.**

LanternOS is a clean-slate operating system — not a Linux distribution, not a Unix clone,
not a browser OS. It explores what an OS would look like if designed today with AI agents,
cryptographic identity, decentralised networking, hardware isolation, open ISAs, and
memory-safe languages available from the very beginning.

We are **architecture-first**: documentation, threat models, and RFCs come before code.
